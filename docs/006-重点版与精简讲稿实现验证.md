日期：2026-11-24

对应需求：[001-需求说明.md](001-需求说明.md) 中的 3.7 和 AC-21 至 AC-27。

## 已实现

- 结果页提供七个同级页签：视频信息整理、视频重点、教学讲稿、精简讲稿、关键图片、全部截图、任务详情。
- 新视频链接在完整 Markdown 保存后，自动调用所选模型生成 `视频重点.md` 和 `精简讲稿.md`。精简失败或模型不可用时保留完整产物及其完成结果。
- 历史任务提供“生成重点版”“重新提炼两份文档”和“重新提炼本页”入口。读取磁盘现有 Markdown，文件写回原任务目录，不复制媒体或重建视频处理任务。
- 历史精简任务使用独立持久化作业记录，与视频处理共用受控队列；进度、取消和异常退出处理沿用队列保护机制，原视频任务状态不被改成处理中或失败。
- 优先读取 `视频信息整理.md`，兼容旧的 `视频解析.md` 和 `学习笔记.md`；精简讲稿以完整 `教学讲稿.md` 为主，并结合有效的视频重点进行核对。
- 长文分段完整处理后，全局合并和去重。范围记录包含连续起止位置及内容指纹；不只发送开头，也不在本地截断源文档。
- 分段模型结果独立保存，失败后可继续；输入与模型不变时复用成功结果。仅调整全局合并规则时，严格验证兼容性后复用分段提炼结果。
- 保存源文件指纹、模型、提示词版本及生成状态，源文档变化后显示过期。生成期间检测源文件变化，避免发布与当前源文件不符的新版本。
- 缺少源文件、部分源内容、模型未配置、处理中及失败均有明确状态。一份失败不影响另一份及完整文档。
- 输出不内嵌图片，只保留少量核心图片引用；精简讲稿仍含连贯旁白和关键动画动作。
- 两份文件支持独立预览、下载及 ZIP 导出。

## 使用

### 新链接

选择已配置的外部模型，正常提交链接。完整图文整理和讲稿完成后，自动进入“重点提炼”。完整文件已可查看，精简状态独立展示。选择本地模式时不会自动调用外部模型，页面提示精简需要模型。

### 已有任务

1. 打开原任务，在上方选择已配置密钥的外部模型；文字模型也可用于精简，无需图片能力。
2. 点击“生成重点版”，基于现有 Markdown 生成两份新文件。
3. 点击“视频重点”或“精简讲稿”查看和下载。
4. 失败后点击生成入口继续；已成功的分段会复用。需要主动重做时使用重新提炼入口。

## 内容边界

模型提炼以现有 Markdown 为依据，不会重新辨认原始图片或修正源文档中的事实错误。姓名、花色、金额、范围与 EV 等仍需对照完整版本和证据核对。部分内容或历史草稿保留完整性提示，精简不能把未知内容变成确定事实。
