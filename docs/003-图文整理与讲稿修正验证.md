修正后的流程：

3. 将已经融合的文字信息提交给模型，独立生成教学讲稿及分镜。
4. 图片分析与讲稿分别保存状态。讲稿失败时保留图片及信息整理；重试可复用成功的图片分析和讲稿片段。
5. 分镜若把总览图回顾的牌局时间误写为来源时间，可在存在有效图片引用时按截图实际时间定位，并记录待核对说明；缺少有效证据时只拒绝该讲稿片段，不拒绝图片分析。
