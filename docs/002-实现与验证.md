# 德州扑克教学内容生产：实现与验证

日期：2026-11-24

对应需求：[001-需求说明.md](001-需求说明.md)。

## 已实现的行为

1. 截图间隔新增 3、5、10 秒，默认 5 秒，保留 15、30、60、120 秒。公开媒体和浏览器播放提取均移除 60 张上限；浏览器提取不再提前通过低分辨率指纹丢弃相似图片。截图保留原视频时间戳。
2. 新任务在获得视频标题后使用“标题_任务ID”目录。处理非法字符并限制标题长度；旧的任务 ID 目录仍可正常读取，不批量迁移历史任务。
3. 图片分析使用全部采样原图，按时间、文字输入大小、图片数量和图片请求大小分批。默认每批最多 6 张，可通过模型配置的 `maxImagesPerBatch`、`maxImageBytes` 调整。接口因参数或请求大小拒绝、输出截断或遗漏图片时，会在可拆分的图片批次内自动拆小重试；其他错误明确记录，不会显示为完整成功。
4. 记录每批图片路径、状态、尝试次数、分析输出和整体覆盖进度。相同素材、模型、提示词和处理选项下，重试复用已完成批次。素材、模型或提示词等发生变化时重新分析，避免混用旧结果。
5. 分批输入包含对应时间的字幕和 OCR，补充跨批次边界的字幕；使用前段内容作为连续性背景。课程结构分层汇总，最终文档仍保留全部批次的详细分析和教学分镜。
6. 输出视频解析、教学讲稿和结构化教学分镜，包含原文整理、背景、策略理由与适用条件、初始牌桌状态、动画动作、旁白、标注、决策问题及待核对项。讲稿标明原视频表达、模型推断或教学改编，并关联证据时间与关键图片。
7. 模型逐图分析后筛选关键图片。完全相同的原图可合并；相似图片仅在模型明确指认为重复、牌局与画面状态一致且 OCR 一致时保守合并。位置、手牌、公共牌、花色、底池、筹码、行动或教学文字变化应保留；未知状态不据此作语义合并。
8. 页面新增视频解析、教学讲稿、关键图片和全部截图入口。关键图片按视频顺序展示，附说明和保留原因，点击可放大查看。页面显示图片与批次进度，失败后可继续分析。
9. 单文件下载和 ZIP 导出包含新文档、分镜、关键图片及分析覆盖记录。仅允许下载明确列出的任务文件。

## 使用方法

1. 打开本地网页，选择支持图片的模型，勾选“分析全部截图”。仅文字模型需要取消图片分析，页面会明确提示能力限制。
2. 选择 3、5 或 10 秒间隔，提交视频链接。
3. 完成后分别查看视频解析、教学讲稿和关键图片；需要核对时查看全部截图及完整转录。
4. 对已有任务，可选择新间隔后点击“用所选模型重新总结”。公开媒体存在源视频时会重新采样，新建任务保留原任务结果；无源视频且需要改变间隔时，应重新提交原视频链接。
5. 部分批次失败时点击“重试失败批次”；课程结构汇总等后续步骤失败时可点击“继续教学分析”。重试会创建新任务，并复用一致配置下的成功批次。

## 产物

任务产物继续保存在 `artifacts/tasks/<标题_任务ID>/`，主要新增：

| 文件或目录 | 用途 |
| --- | --- |
| `视频解析.md` | 原视频背景、语音、策略与画面证据 |
| `教学讲稿.md` | 学习目标、旁白、动画分镜与教学内容 |
| `教学分镜.json` | 结构化课程和分镜，供后续工具读取 |
| `关键图片.json` | 保留图片、逐图分析、重复判定与原图映射 |
| `keyframes/` | 筛选后的关键图片 |
| `analysis-progress.json` | 批次输出、失败状态、覆盖进度和复用依据 |

`学习笔记.md` 保留为视频解析的兼容入口。`images/` 继续保留全部采样原图，方便人工核对。

## 验证结果

- 自动检查共 31 项通过，涵盖原有核心功能、模型适配、Worker、本次分批分析和文件接口。
- 使用实际 FFmpeg 从合成视频中按 3 秒提取 62 张截图，验证已取消 60 张上限。
- 用 101 张图片验证批次规划覆盖完整，并覆盖字幕空白时段。
- 模拟 15 张图片中的一个批次失败，再次运行仅补齐失败图片，成功批次不重复发送；更换模型后重新分析全部图片。
- 模拟接口单次最多接受 2 张图片，验证自动拆分后所有图片都被分析。
- 验证底池、花色、行动变化及未知状态不会被错误合并。
- HTTP 检查覆盖新旧目录、文档下载、关键图片下载、ZIP 内容和非法文件访问。
- TypeScript 检查和 Vite 生产构建通过。
- 使用 Chrome 检查真实历史任务的 30 张截图仍可查看；检查新讲稿及关键图片页面、图片加载和 Markdown 图片引用。桌面及 390 像素手机宽度无页面脚本错误和横向溢出。

## 实际使用边界

- 模型分析与界面验证使用模拟模型响应，尚未用新版流程重新调用付费模型处理用户现有视频。真实图片识别准确性、长视频分析耗时和模型输出质量仍需实际视频验收。
- 全量图片分析会增加模型请求、费用、OCR 时间和磁盘占用。预置模型输出上限从 6000 调整为 12000 tokens，以容纳逐图分析和教学分镜。
- 去重采用保守策略，宁可保留部分相似图片，也不轻易删除牌面或下注变化。模型判断不能替代人工核对。
- 固定间隔截图无法保证捕捉所有瞬时动作；本次未增加画面变化触发采样，也未接入动画生成或课程发布工具。
- 本地模式或关闭图片分析时，不声称已经完成图片理解和模型关键图片筛选。
