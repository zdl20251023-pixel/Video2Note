# Video2Note

本地视频学习笔记工具，支持 YouTube、B站和 PokerCoaching。提供字幕提取、可选语音识别、截图与本地 OCR，以及可配置的模型语义总结和 Markdown/ZIP 导出。

## 安装与启动

环境：Windows、Node.js 22.18 或兼容的更新版本、Google Chrome。请在正常 PowerShell 中运行，确保服务可访问互联网。

```powershell
npm.cmd ci
npm.cmd run setup:media
npm.cmd test
npm.cmd run build
npm.cmd start
```

打开 http://127.0.0.1:3210/ 。如旧项目服务仍占用 3210 端口，先关闭它，或设置 `$env:PORT = '3211'` 后启动新项目。

开发模式：`npm.cmd run dev`，或双击 `启动本地工具.cmd`。不要在同一端口同时运行开发和生产服务。

## 使用

1. 粘贴单个视频页面地址，自动识别平台。
2. 首次默认 DeepSeek。点击“模型设置”保存本人的 API Key 并测试连接；也可选择本地原文整理。
3. YouTube/B站公开视频通常无需登录。平台要求登录时，使用网页的独立 Chrome 登录窗口，完成后点击“确认已登录”。
4. 选择截图间隔、OCR、是否结合截图，以及无字幕时是否使用 DeepSeek 语音识别，提交任务。
5. 查看学习笔记、截图与转录，下载 Markdown 或完整文件包。

本地原文整理不调用总结模型，也不自动发送音频。模型模式会发送所选字幕、OCR 和可选截图；启用无字幕语音识别时会分段上传音频，各服务按自身规则收费。

语音识别时间戳按约 30 秒音频分段定位，不是逐字或逐句精确对齐。OCR 和模型的术语、牌面及数字需要结合原始材料核对。

## 模型配置

编辑 `config/models.json` 后，在网页点击“刷新模型配置”即可增加或调整 OpenAI Chat Completions 兼容的服务商和模型。预置 DeepSeek 和 Gemini；其他原生协议需另加适配器。

`apiKeyEnv` 是环境变量名称，不是真实密钥。真实密钥通过网页保存于本机 `.local/`，也可由配置指定的后端环境变量提供。环境变量改变后需重新启动服务。

## 文件与运行数据

每个任务独立保存在 `artifacts/tasks/<任务ID>/`，包含学习笔记、完整转录、音频、截图、字幕及处理元数据。模型重新总结会创建新任务并复用素材，不覆盖原结果。

`.local/` 保存密钥、站点会话、浏览器资料、任务数据库和视频提取工具；`artifacts/` 保存任务产物。它们都不应提交 Git。新安装不含旧项目的密钥、登录状态、历史任务、视频和样例素材，需要重新配置本人凭据。

旧验证样例不是核心功能的前提。未安装样例素材时，“已验证素材体验”入口自动隐藏，不影响正常链接处理。

YouTube/B站使用项目内 yt-dlp 和 FFmpeg；可以通过网页更新提取工具。PokerCoaching 使用正常浏览器播放提取，处理时保持登录窗口开启。

## 源码

- `web/`：React + TypeScript 网页。
- `server/`：本地服务、任务队列、平台适配、语音识别与笔记整理。
- `config/`：非敏感模型配置。
- `scripts/`：核心安装、登录与完整性验证辅助函数。
- `tests/`：核心自动测试，不依赖旧视频产物。

本项目仅监听本机地址。会员、地区和账号权限仍决定视频可获取范围；暂不批量抓取播放列表、整套课程或直播。
